# FUTURE FANTASY ─未来の地図─ ティザーサイト

本編が完成するまでの間に出す、一枚絵のティザー画面です。
完成形の一枚絵を部品ごとのレイヤーに分解し、順番に立ち上げてから、
静かに動き続ける状態に落ち着きます。

> 60年の軌跡、ここから新たな冒険へ。─舞台は仙台。　2027.1.22-24

## 動かし方

ビルドは不要です。どんな静的サーバーでも動きます。

```
python3 -m http.server 8000
# → http://localhost:8000/
```

Service Worker と `manifest.webmanifest` を含むため、HTTPS（または localhost）で開けば
ホーム画面に追加でき、PWA の起動画面として成立します。

公開先: https://takiyaoffice.github.io/tiser/

## 入口

最初に出るのは、黒い画面に一行だけの

> ▶タップ シテ モノガタリ ヲ ハジメル

です。ここに触れたところから演出が動きはじめ、同時に音も解錠されます。
ブラウザは利用者が画面に触れるまで音を鳴らせない決まりなので、
「触れてもらう場所」と「音を許してもらう場所」を一つにしてあります。

文字は 16x16 のビットマップ書体（Unifont JP）で一度だけ描き、
あとは整数倍に引き伸ばしているので、角が丸くならずドラクエの窓文字のように見えます。
`tools/make_hero.py` の `build_tap()` が `assets/img/hero/tap.webp` を書き出します。

`prefers-reduced-motion` が有効な環境では入口を出さず、完成形をそのまま表示します
（音は右下のボタンから入れてもらいます）。

## 初回演出

時刻はすべて「タップした瞬間」からの経過です。

| 順 | 出るもの | 時刻 | 動き |
|---|---|---|---|
| 1 | 60TH の盾（画面のど真ん中・小さめ） | 0.50s | 黒画面に小さく浮かび（光輪は付けない）、しばらく留まったあと、ぼやけながら広がって霧のように消える |
| 2 | 背景 | 3.90s | 少し寄った状態から引きながら現れる。霧が晴れるのと重なる |
| 3 | 60TH の盾（左上） | 5.10s | 完成形の位置に据わり、以後ずっと居続ける |
| 4 | FUTURE FANTASY | 6.30s | 大きめ・ぼけた状態から寄ってきて、着地にあわせて光が差す |
| 5 | 60年の軌跡、… | 8.60s | 下からゆっくり上がり、ぼけが取れる（1.9秒かける） |
| 6 | ─舞台は仙台。 | 9.80s | 同上 |
| 7 | 区切り線 | 10.90s | 中央から横に伸びる |
| 8 | 2027.1.22-24 | 11.40s | 同 5 |
| 9 | 区切り線 | 12.70s | 同 7 |
| 10 | A new adventure is coming… | 13.20s | 同 5（2.0秒かける） |

全体で約 15.2 秒です。時刻を変えるときは `assets/js/hero.js` の `STEPS` を直してください。
`prefers-reduced-motion` が有効な環境では演出を飛ばし、完成形をそのまま表示します。

## 落ち着いたあとの動き

- **背景** 72秒かけて、ごくゆっくり寄り引きする
- **空** 雲のテクスチャを `soft-light` で 16% 重ね、200秒で流す。空の部分だけにマスクをかけている
- **夕日** 地平線の光が 23秒周期で明るさを変える
- **光の粒** 1.9〜4.7秒に一粒ずつ生成。同時に最大 11 粒、11〜20秒かけて漂って消える。5粒に1粒くらいは大きめ
- **60TH** 9秒周期でほのかに明滅する
- **FUTURE FANTASY** 13秒ごとに、表面を光が斜めに走る（エンブレムの形でマスクしている）
- **流れ星** 17〜38秒に一筋、空の上側（高さ 4〜30%）を細く横切る。1秒前後で消え、
  3割ほどの確率で続けてもう一筋流れる。エンブレムや文字より奥にあるので、その裏を通る

## 隠された入口

落ち着いてしばらくすると、画面の光がゆっくり左上の 60TH へ吸い込まれていきます。
真っ暗にはせず（いちばん暗いところでも不透明度 0.93）、紋章のまわりだけが残ります。
紋章はわずかに息をし、そのわきに一言だけ置かれます。

> まだ、気づいていない道がある。

紋章にふれると光があふれ、`SECRET PATH DISCOVERED` のあとに
「THE ADVENTURE AWAITS」の札が立ち上がり、旅の書（別サイト）への道がひらきます。

| | はじめての人 | 一度見つけた人 |
|---|---|---|
| 暗くなりはじめる | 落ち着いてから 7.0s | 2.0s |
| 暗くなりきる | 16.0s かけて | 5.5s かけて |
| 一言が出る | 暗転のはじめから 8.0s | 1.6s |

一度ひらいた人は端末に覚えさせ（`ff-path`）、次からは長い暗転を繰り返しません。
時間を変えるときは `assets/js/hero.js` の `LURE` と `LURE_BACK` を直してください。

- **行き先は `assets/js/hero.js` の `APP_URL` ひとつで決まります。**
  `index.html` のリンクにも同じものを書いてありますが、読み込み時に上書きされます
- 幕は `pointer-events: none` なので、ふだんの閲覧や右下の音のボタンを妨げません
- 触れる範囲は紋章の見た目より一回り広く、横に 1.84 倍・縦に 1.6 倍とってあります
  （実寸から測って置いているので、画面の大きさや向きが変わってもついてきます）
- ボタンらしい見た目は持たせていません。手がかりは、光と一言と紋章の息づかいだけです
- `prefers-reduced-motion` が有効な環境では、暗転の過程を飛ばして結果だけを出します

## 音

入口に触れた時点で鳴る状態になります。切りたいときは画面右下の小さなボタンで止めます。

ボタンは枠も下地も持たず、透かしのように薄く（不透明度 0.3）置いてあります。
触れるか音を入れると 0.68 まで濃くなります。絵の邪魔をしない右下の暗いところに配置しています。

- **黒い画面のあいだは鳴りません。** 背景が現れる 3.90 秒から始まります
- タップした瞬間には、黙らせたまま鳴らしはじめています。
  iOS は「触れた、その処理の中で」再生を始めないと鳴らしてくれないためです。
  3.90 秒で曲の頭に戻し、そこから音量を上げます
- iPhone は `audio.volume` を受け付けません（音量は本体側のものとされています）。
  0 にしたつもりでもそのまま鳴ってしまうので、音量の上げ下げは Web Audio の
  つまみ（GainNode）で行い、黒画面のあいだは `muted` でも二重に押さえています
- ボタンは背景と一緒に現れます。入口の黒い画面には、あの一行しか置きません
- 曲は 48.9 秒の繰り返しで、いつ音を入れ直しても頭から流します
- 音量は 1.6 秒かけて上げ、切るときは 0.5 秒で下げます
- 他のタブへ移ると止まり、戻ると再開します
- 入り切りの状態は端末に覚えさせます。前回わざわざ切った人には、タップしても鳴らしません
- ブラウザに止められただけのときは覚えません（次に開いたらまた試します）

音源は `assets/audio/theme.mp3`（48.9秒・192kbps・1.1MB）です。
`preload="auto"` にしてあるので、黒い画面を読んでもらっているあいだに用意しておきます。

`tools/make_bgm.py` は、別案として合成した曲を `theme-synth.mp3` に書き出します。
現在サイトで使っている音源は上書きしません。

```
python3 tools/make_bgm.py     # 別案を assets/audio/theme-synth.mp3 に書き出す
```

## ファイル構成

```
index.html                     画面の骨組み。要素のレイヤーだけを持つ
manifest.webmanifest           PWA 設定（縦固定・スタンドアロン・背景 #05070c）
sw.js                          オフライン用の最小キャッシュ
assets/css/hero.css            配置と動きの実体
assets/js/hero.js              入口、演出の進行、光の粒、流れ星、音、隠された入口
assets/audio/theme.mp3         BGM（48.9秒・繰り返し再生）
assets/img/hero/*.webp         書き出し済みの表示用素材（生成物）
assets/img/clouds.png          空を流れる雲のテクスチャ（生成物）
assets/img/icon-*.png          PWA アイコン（生成物）
assets/img/splash/             iOS の起動画像（生成物）
assets/img/parts/              受け取った元素材（配信しない）
assets/img/teaser-source.png   前身のポスター。英文一行の切り出し元（配信しない）
tools/make_hero.py             画像の「生成物」を作り直すスクリプト
tools/make_bgm.py              BGM の別案を合成するスクリプト
```

素材を作り直す場合:

```
pip install Pillow numpy opencv-python-headless
python3 tools/make_hero.py
```

## 配置の考え方

完成形（`assets/img/parts/hero-composite.png`、853 x 1844）と同じ縦横比の「枠」を作り、
その中に **%座標** で部品を置いています。数値は完成形から実測したものです。

| 部品 | 左 | 上 | 幅 |
|---|---|---|---|
| 60TH | 5.01% | 6.14% | 15.47% |
| FUTURE FANTASY | 20.63% | 12.91% | 60.84% |
| リード文 | 17.47% | 38.61% | 65.18% |
| 日付 | 31.54% | 47.40% | 37.40% |
| 英文 | 22.75% | 53.69% | 54.51% |

**枠の幅は画面の幅にそろえます。** 縦は絵の比率のまま伸び、画面からはみ出した分は
下から切れます。文字はすべて上半分に入っているので、縦の短い端末でも欠けません。
横長の画面（縦横比 0.625 以上のタブレットや PC）では、絵の全体が入るように収め、
背面にぼかした同じ絵を敷いて余白を埋めます。

## 素材について

- 背景は文字の入っていない `parts/scene-base.png` を使っています。完成形の背景とは
  別に描かれた絵なので、空や山の細部はわずかに異なります
- リード文は「一行ずつ」出せるよう、元素材を 2 行に切り分けています
- 「A new adventure is coming…」だけは素材が無かったため、前身のポスターから
  明暗差を透明度に変換して切り出しました
- 区切りの飾りは CSS で描いています
- 最初に出る 60TH は画面幅の 13%（縦が短いときは画面高さの 8.5% で頭打ち）。
  iOS の起動画像も同じ大きさ・同じ位置に置いてあるので、起動から 1 コマ目へ切れ目なくつながります
