# Takutendo ─ 仙台への冒険 ティザーTOP画面

本編（仙台旅行アプリ）が完成するまでの間に表示する、ティザー用のTOP画面です。
画面上部に赤いヘッダー（Takutendo）、その下に動くポスターが入ります。

> これはゲームではない。二人の旅行が、もうすぐ冒険になる。

一枚のポスターとして完成している静止画の上に、ごく薄い動きだけを重ねています。
ぱっと見は静止画、じっと見ていると雲・光・茶々丸・草花が動いていることに気付く、という状態を目指しています。

## 動かし方

ビルドは不要です。どんな静的サーバーでも動きます。

```
python3 -m http.server 8000
# → http://localhost:8000/
```

Service Worker と `manifest.webmanifest` を含むため、HTTPS（または localhost）で開けば
そのままホーム画面に追加でき、PWA の起動画面として成立します。

## ファイル構成

```
index.html                     画面の骨組み。エフェクトのレイヤーだけを持つ
manifest.webmanifest           PWA 設定（縦固定・スタンドアロン・背景 #0a0806）
sw.js                          オフライン用の最小キャッシュ
assets/css/teaser.css          レイアウトとエフェクトの実体
assets/js/teaser.js            座標定義・初回演出の進行・光の粒の生成
assets/img/teaser-source.png   原画（853 x 1844・無加工。配信はしない）
assets/img/teaser.png          配信用ポスター（原画の日付だけを差し替えたもの・生成物）
assets/img/teaser.webp         同じ絵の WebP 版（初回表示を軽くするため・生成物）
assets/img/plate/*.webp        文字が現れる前の「文字が無い状態」の当て板（生成物）
assets/img/clouds.png          雲用のシームレスなノイズテクスチャ（生成物）
assets/img/icon-*.png          PWA アイコン（生成物）
assets/img/splash/             iOS の起動画像（生成物）
tools/make_assets.py           上記「生成物」を作り直すスクリプト
```

派生アセットを作り直す場合:

```
pip install Pillow numpy opencv-python-headless
python3 tools/make_assets.py
```

## 元画像の扱い

**原画 `assets/img/teaser-source.png` は書き換えません。** 構図・色・世界観はそのままです。

配信用の `teaser.png` は、原画から**日付の一行だけ**を差し替えたものです。
古い日付を周囲の空で塗りつぶし、同じ位置・同じ高さ・同じ字送り・同じ金の階調で
`2027.1.22 — 1.24` を描き直しています。差し替え内容は
`tools/make_assets.py` の `NEW_DATE` を変えれば作り直せます。

画面は元画像と同じ縦横比（853:1844 ≒ 0.4626）の「ステージ」を作り、その中に
`background-size: 100% 100%` で敷いています。比率が一致しているので画像は歪みません。
端末の比率が違うときは、背面にぼかした同じ絵を敷いて余白を埋めます。

演出はすべて、このステージに対する **%座標** で重ねています。
位置の指定は `assets/js/teaser.js` の `PATCHES` と `VEILS` に、
元画像のピクセル座標（853 x 1844 基準）で書いてあるので、そこだけ直せば調整できます。

## エフェクト

| # | 内容 | 実装 |
|---|------|------|
| 1 | 空・雲 | 別テクスチャを `soft-light` で 6〜14% だけ重ね、72秒／140秒かけて横へ流す。14〜19秒周期で濃淡も呼吸する。文字が並ぶ帯（高さ 15〜42%）ではマスクで 1/5 に弱め、金の額縁にはかからない |
| 2 | 光の粒 | JS が 2.2〜4.8 秒に 1 粒ずつ生成。同時に最大 9 粒、9〜16 秒かけて漂って消える |
| 3 | 地図アイコン | 地図部分の画像を `screen` で重ね、7.6 秒周期で「暗い→少し光る→暗い」を繰り返す。金の線だけが浮かび上がる |
| 4 | 茶々丸 | 尻尾は付け根を軸に 9.5 秒周期で ±2.6°。耳は 13 秒に 2 回だけ小さく動く |
| 5 | 草・花 | 猫のとなりの草花と崖ぎわの下草を、11 秒周期で 1〜2px ぶんだけ傾ける |
| 6 | 霧・空気 | 谷筋に薄い帯を 3 本、118〜201 秒かけて流す |
| 7 | 光の差し込み | 夕日（右 92% / 上 50.5%）を中心にした淡い光と光条。21 秒／29 秒でゆっくり明るさが変わる |

### 4・5 の仕組み

猫や草花は元画像に描き込まれているため、その部分だけを動かすのに
「同じ画像を同じ位置・同じ大きさで重ね、わずかに回転／傾ける」という方法を使っています。

静止しているときは元画像と完全に一致するので、重ねていること自体が見えません。
動いたときだけ、ずれた分の周囲（岩や地面）が元の尻尾を塗りつぶし、新しい角度に描き直されます。
支点（`pivot`）を尻尾の付け根に置いているので、体の側はほとんど動きません。

## 初回表示の演出

ページを開くと、文字が一つずつ浮かび上がります。全体で約 6.1 秒です。

1. 背景画像（0.15s〜）
2. THE ADVENTURE（1.15s〜）
3. 仙台への冒険（1.65s〜）
4. 60年の軌跡、ここから新たな冒険へ。（2.45s〜）
5. 2027.1.22 — 1.24（2.95s〜）
6. A new adventure is coming…（3.45s〜）
7. 地図アイコン（3.95s〜）
8. まもなく、冒険がはじまる。（4.75s〜）

**文字を黒い幕で隠してはいません。** 代わりに、その部分だけ
「文字が無い状態の絵」（`assets/img/plate/*.webp`）を重ねてあります。
だから演出中の画面にも黒いもやは出ず、空も谷もつながって見えます。
当て板が消えると、何も無かったところに文字が浮かび上がります。

当て板は `tools/make_assets.py` が作ります。文字とその外側の暗い縁をまとめて
選び出し、少し離れた場所の色で塗り直したうえで、置き換えるのは文字のあった
範囲だけに絞っています（周囲の雲をそのまま残すため）。地図アイコンのように
面が広いところは、境界の色を保ったまま拡散させて埋め、近くの地形のきめだけを
借りて戻しています。

タイミングを変えるときは `assets/js/teaser.js` の `PLATES` の `at` と `for` を調整してください。

## 画面まわり

- 画面上部は赤（#e60012）のヘッダー。高さ 52px、中央に Takutendo
- ポスターはヘッダーの下の残り全部に、縦横比を保ったまま収まる
- スマートフォン優先・縦長・スクロールなし。ヘッダー以外の UI は無し
- iPhone のアドレスバー分を含む実寸を JS から `--app-h` に渡し、表示が切れないようにしている
- OS の「視差効果を減らす／動きを減らす」設定が有効な場合は、演出を止めて一枚絵として表示する
- JavaScript が無効な環境では、暗幕が出ないまま元のポスターがそのまま表示される
