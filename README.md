# FUTURE FANTASY ─未来の地図─ ティザーサイト

本編が完成するまでの間に出す、一枚絵のティザー画面です。
完成形の一枚絵を部品ごとのレイヤーに分解し、順番に立ち上げてから、
静かに動き続ける状態に落ち着きます。

> 60年の軌跡、ここから新たな冒険へ。─舞台は仙台。　2027.1.22-24

## 動かし方

ビルドは不要です。どんな静的サーバーでも動きます。

```
python3 -m http.server 8000
# → http://localhost:8000/
```

Service Worker と `manifest.webmanifest` を含むため、HTTPS（または localhost）で開けば
ホーム画面に追加でき、PWA の起動画面として成立します。

公開先: https://takiyaoffice.github.io/tiser/

## 落ち着いたあとの動き

- **背景** 72秒かけて、ごくゆっくり寄り引きする
- **空** 雲のテクスチャを `soft-light` で 16% 重ね、200秒で流す。空の部分だけにマスクをかけている
- **夕日** 地平線の光が 23秒周期で明るさを変える
- **光の粒** 1.9〜4.7秒に一粒ずつ生成。同時に最大 11 粒、11〜20秒かけて漂って消える。5粒に1粒くらいは大きめ
- **60TH** 9秒周期でほのかに明滅する
- **FUTURE FANTASY** 13秒ごとに、表面を光が斜めに走る（エンブレムの形でマスクしている）

## ファイル構成

```
index.html                     画面の骨組み。要素のレイヤーだけを持つ
manifest.webmanifest           PWA 設定（縦固定・スタンドアロン・背景 #05070c）
sw.js                          オフライン用の最小キャッシュ
assets/css/hero.css            配置と動きの実体
assets/js/hero.js              演出の進行と、光の粒の生成
assets/img/hero/*.webp         書き出し済みの表示用素材（生成物）
assets/img/clouds.png          空を流れる雲のテクスチャ（生成物）
assets/img/icon-*.png          PWA アイコン（生成物）
assets/img/splash/             iOS の起動画像（生成物）
assets/img/parts/              受け取った元素材（配信しない）
assets/img/teaser-source.png   前身のポスター。英文一行の切り出し元（配信しない）
tools/make_hero.py             上記「生成物」を作り直すスクリプト
```

素材を作り直す場合:

```
pip install Pillow numpy opencv-python-headless
python3 tools/make_hero.py
```

## 配置の考え方

完成形（`assets/img/parts/hero-composite.png`、853 x 1844）と同じ縦横比の「枠」を作り、
その中に **%座標** で部品を置いています。数値は完成形から実測したものです。

| 部品 | 左 | 上 | 幅 |
|---|---|---|---|
| 60TH | 5.01% | 6.14% | 15.47% |
| FUTURE FANTASY | 20.63% | 12.91% | 60.84% |
| リード文 | 17.47% | 38.61% | 65.18% |
| 日付 | 31.54% | 47.40% | 37.40% |
| 英文 | 22.75% | 53.69% | 54.51% |

**枠の幅は画面の幅にそろえます。** 縦は絵の比率のまま伸び、画面からはみ出した分は
下から切れます。文字はすべて上半分に入っているので、縦の短い端末でも欠けません。
横長の画面（縦横比 0.625 以上のタブレットや PC）では、絵の全体が入るように収め、
背面にぼかした同じ絵を敷いて余白を埋めます。

## 素材について

- 背景は文字の入っていない `parts/scene-base.png` を使っています。完成形の背景とは
  別に描かれた絵なので、空や山の細部はわずかに異なります
- リード文は「一行ずつ」出せるよう、元素材を 2 行に切り分けています
- 「A new adventure is coming…」だけは素材が無かったため、前身のポスターから
  明暗差を透明度に変換して切り出しました
- 区切りの飾りは CSS で描いています
